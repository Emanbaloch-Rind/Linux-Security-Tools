# Nmap Network Scanning

## Introduction
Nmap (Network Mapper) is a network scanning tool used to discover devices, identify open ports, and collect information about network services.

## Objective
To learn how to use Nmap for network discovery and port scanning.

## Tool Used
- Kali Linux
- Nmap

## Practical Tasks
1. Network host discovery
2. TCP SYN scan (-sS)
3. TCP connect scan (-sT)
4. UDP scan (-sU)
5. TCP FIN scan (-sX)
6. Operating system detection (-O)

## Learning Outcome
I learned how Nmap discovers network devices, scans ports, and helps identify services running on a network.

## Note
All scanning activities should be performed only on networks and systems where permission has been granted.
